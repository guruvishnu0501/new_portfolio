A creative, modern, professional, and production-ready personal developer portfolio built with React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

## 💎 Design Philosophy & Personality

- **Futuristic & Technical:** Near-black obsidian (`#07080C`) background with electric cyan (`#00F2FE`) and violet accents.
- **AI-Inspired & Interactive:** Lightweight HTML5 Canvas interactive neural network, interactive AI pipeline sandbox, and interactive developer terminal (`guru@portfolio:~$`).
- **Authentic & Factual:** 100% grounded in verified resume facts with zero hallucinated companies, metrics, or fake skill bars.
- **Recruiter & Engineer Friendly:** Deep case study modals with animated inference pipeline flows (Input → Preprocessing → ML Model → Prediction → User Experience).

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/guruvishnu0501/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the live website.

### Production Build

```bash
npm run build
```

The production assets will be generated in the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.
